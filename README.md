Portfolio Website: 
A MERN stack based personal portfolio to showcase my projects, skills, and contact details.

Live Demo: 
 https://mern-portfolio-frontend-qaf3.onrender.com

Tech Stack:-
React.js
Node.js
Express.js
MongoDB

 Structure: 
mern-portfolio/
├── frontend/
├── backend/

Frontend:-
cd frontend ,
npm install ,
npm start

Backend:-
cd backend , 
npm install ,
npm run dev
